# 中国科学院计算技术研究所报考指南

面向准备报考中国科学院计算技术研究所的同学整理的非官方公益指南。

网站使用 MkDocs Material 构建，并通过 GitHub Actions 自动发布到 GitHub Pages：

- 网站地址：<https://ict.cskaoyan.cn/>
- 官方招生信息：<https://www.ict.ac.cn/yjsjy/zsxx/>

## 本地预览

```powershell
python -m pip install -r requirements.txt
python -m mkdocs serve
```

访问 <http://127.0.0.1:8000/>。

## 内容维护

所有页面源文件都在 `docs/`。修改 Markdown 后推送到 `main` 分支，GitHub Actions 会自动构建和发布网站。

涉及招生政策、分数线和录取数据时，请注明信息年份、更新时间和官方来源。
