# 前瞻研究实验室

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册将前瞻研究实验室描述为多个差异较大的研究组联合体，研究覆盖媒体计算、虚拟现实、生物信息、算法理论和分布式计算等方向。

## 主要研究方向

- 跨媒体计算
- 虚拟现实、可视计算和人体运动仿真
- 算法复杂性、量子计算与密码学基础
- 生物信息学与分布式云计算

## 内部课题组

### 跨媒体计算课题组

围绕互联网虚假伪造内容检测开展研究，方向包括谣言检测、图像与视频生成检测、文本生成、自然语言处理和社交媒体隐私保护。

### 虚拟现实技术研究组

研究虚拟现实与增强现实、人机交互、计算机图形学和可视化，对物理基础与编程能力均有一定要求。

### 可视计算课题组

研究全景相机、计算摄影、全景视觉分析、三维感知与可视化。

### 人体运动仿真研究组

围绕人体运动仿真、计算机图形学、虚拟现实与增强现实开展科研和工程工作。

### 量子计算与算法理论实验室

研究量子计算、通信复杂度、图论、组合优化、在线算法、随机性与去随机化、密码学基础、机器学习和分布式计算理论。

### 生物信息卜东波与孙世伟课题组

偏重算法设计与分析、SAT 求解，以及理论算法与生物信息计算的结合。

### 生物信息 pFind 课题组

聚焦蛋白质组学数据分析、生物信息算法、质谱数据处理和科研软件工程。

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
