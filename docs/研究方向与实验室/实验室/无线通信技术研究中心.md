# 无线通信技术研究中心

!!! warning "手册原文整理"
    以下内容根据《2025版计算所信息手册 2.0》扫描页整理，保留了手册中的实验室背景、团队、导师、培养、项目、待遇与就业等描述。手册并非官方材料，其中的个人评价和时效性信息未经本站核验，不代表本站事实判断；报考前请向实验室和导师本人确认。

手册将无线通信中心概括为两个主要部分，由两位博导带领并形成两个方向：一是周一青老师团队带领的传统通信方向，以无线通信为主；二是石晶林老师团队带领的芯片通信及应用方向。两位老师下面还有不同老师分别带领组内成员。

周老师项目组按照传统意义上的计算机网络体系结构划分方向，涉及物理层、链路层、网络层等通信研究。手册称石老师同时承担公司管理工作，因此学生可能根据项目需要进入周老师团队，也可能由莫志锋老师或公司的工程师指导。石老师团队学生更倾向于芯片处理、芯片通信等与芯片联系较多的内容。

在培养体验方面，手册对周老师的责任心和对学生的关照评价很高，也称其对学术要求严谨。手册认为传统通信方向存在行业趋于饱和的问题，博士培养压力较大，但补助较多；AI 与通信交叉方向的就业选择可能更宽，可以进入通信或互联网企业。

对于石老师团队，手册的个人观察认为培养方式较为放养，学生可以外出实习，但自由度较高也要求学生具备自我管理能力。手册同时提到莫志锋老师对学生要求相对宽松，其团队方向包括机器人、卫星芯片和通信芯片等；部分学生也可能由工程师或博士生参与指导。

手册最后认为，通信方向存在许多通信院校共同面对的“方向饱和”问题，但这并不代表中心实力不足；从承担项目看，传统通信强校涉及的研究和工程方向，该中心基本也有覆盖。
