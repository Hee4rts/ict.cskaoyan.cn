# 无线通信技术研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册介绍该中心围绕无线通信、通信芯片及相关应用开展研究，并提及传统通信与 AI、机器人和卫星应用的交叉。

## 主要研究方向

- 无线通信系统
- 通信芯片与芯片通信
- AI 与通信融合
- 机器人、卫星芯片及相关应用

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
