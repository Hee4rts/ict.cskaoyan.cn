# 智能算法安全重点实验室

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册以该标题引出数据智能系统相关团队，重点面向网络空间治理和安全管理需求。具体组织结构与名称可能随年度调整。

## 主要研究方向

- 智能算法安全
- 网络空间智能感知
- 网络与信息安全
- 社会计算与认知计算

## 数据智能系统研究中心

手册将数据智能系统研究中心作为本部分的重要团队介绍。中心成立于 2020 年，面向网络空间治理和网络空间安全管理需求，研究社交媒体计算、网络数据挖掘、深度学习、网络科学、社会计算和认知计算，并研制网络空间智能感知、智能引导、群智决策和社会模拟等系统。

手册将其组织概括为三个部分：

- 基础研究部：基础研究、学科建设和学生培养
- 核心系统部：核心系统研制、关键技术攻关和纵向课题
- 专项任务部：国家重大任务与工程项目

## 报考时建议确认

- 当年是否招生、招生专业及名额归属

- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
