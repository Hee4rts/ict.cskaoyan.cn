# 处理器芯片重点实验室

!!! warning "手册原文整理"
    以下内容根据《2025版计算所信息手册 2.0》扫描页整理，保留了手册中的实验室背景、团队、导师、培养、项目、待遇与就业等描述。手册并非官方材料，其中的个人评价和时效性信息未经本站核验，不代表本站事实判断；报考前请向实验室和导师本人确认。

计算机体系结构国家重点实验室自2011年成立以来，始终致力于计算机体系结构和系统设计方法的应用基础研究，特别是在超并行计算机系统和多核处理器领域取得了显著成果。实验室不仅在国内保持领先地位，还在国际上率先开展了深度学习处理器和高通量计算等新方向的研究，得到了国际计算机体系结构界的广泛认可。实验室的研究队伍由108名固定人员组成，其中包括3名院士、5名国家杰出青年科学基金获得者和6名国家优秀青年科学基金获得者，具有高级职称的人员占比78.7%，博士学位人员占比89.8%。实验室的研究方向涵盖了高端计算体系结构、微体系结构、编译与编程、VLSI与容错计算以及非传统体系结构等多个领域，目标是建设国际一流的科学研究、技术创新和人才培养基地。

实验室的长期目标是满足高性能计算、智能计算和人机物三元计算的需求，研究十万亿次级芯片体系结构、千线程级芯片体系结构、千万亿次智能计算芯片体系结构以及十万亿次/瓦高能效物端芯片体系结构等关键技术。同时，实验室还致力于研究艾级高性能计算机系统结构、千万线程级高通量计算机系统结构以及海云计算融合的新型计算模式和系统结构。通过这些研究，实验室旨在为未来计算机系统的发展提供科学技术依据，推动我国在计算机体系结构领域的国际竞争力，避免核心技术受制于人，确保国家信息安全和产业自主可控。

### 集成电路实验室

集成电路实验室聚焦于集成电路设计自动化（EDA）、测试验证、硬件安全、专用处理器设计及低功耗技术等核心领域，致力于突破芯片敏捷开发、可靠性保障及 EDA 工具自主化等关键技术，改变我国集成电路核心技术受制于人的局面。实验室现有研究员3人、副研究员2人、助理及工程师3人，承担国家973/863、重点研发计划、自然基金等10余项国家级项目，获国家技术发明奖、科技进步奖等国家级奖项2项，省部级科技奖9项，团队入选“科技北京”百名领军人才培养工程。

实验室研究方向以机器学习硬件加速为核心，传统测试验证方向逐渐淡化。研究组分工如下：

- 李晓维（实验室领导，国家技术发明奖获得者）：统筹实验室工作，学生分配至贵海、王颖团队。

- 鄢贵海：主导区块链加速芯片研发（中科驭数公司），推动金融科技专用芯片落地。

- 叶靖：研究硬件安全与防护（如硬件木马检测、强物理不可克隆函数）。

- 路航：面向嵌入式人工智能与高能效体系结构设计。手册提到实验室通过产学研结合推动芯片设计自主可控与技术创新。

- 李华伟：负责测试与设计验证研究组，学生培养方面比较自由。

### 编译与编程实验室

编译与编程实验室隶属于计算机体系结构国家重点实验室，是国内最早从事编译系统研究与开发的团队之一，曾为国产曙光系统、龙芯芯片等开发高性能编译系统（如LoongCC、二进制翻译系统DBT），显著提升了国产芯片的软件适配性和性能。实验室由冯晓兵研究员领导，现有正高级职称人员3人、副高级职称人员4人，团队规模约20余人。研究方向涵盖编程与编译优化、软件分析与安全两大领域，具体包括并行编程、多核编程、云计算编程、编译优化、系统资源优化及软件分析技术等。

实验室近期聚焦云计算、智能计算、物联网等新型计算场景，致力于开发原创性编程模型、编译优化技术及软件分析工具，支持国产硬件架构和关键应用。研究成果已应用于寒武纪、华为等国产芯片，并在国际学术界和产业界产生重要影响。实验室目标是通过技术创新，推动国产芯片编程环境与编译系统的自主化，培养编程与编译领域的优秀人才，助力我国在相关领域实现技术突破和产业升级。

- 并行编程组：陈莉副研究员是组长。

- 多核编程组（中科编易（北京）科技有限公司）：刘雷博士是组长。

- 云计算编程组：崔慧敏研究员是组长，组内包括赵家程副研究员。

- 软件分析技术组（宁波中科天齐信息技术有限公司：https://www.woocoom.com）：李炼研究员是2015年从Oracle引进的百人计划研究员，研究方向是静态分析，包括软件缺陷和恶意软件检测机制。

### 并行算法研究组

由张云泉研究员负责，主要的研究方向是并行算法与并行软件、并行计算模型、性能优化和性能评测。他之前是中科院软件所并行软件与计算科学实验室的常务副主任，2013年加入计算所。成员包括贾海鹏高级工程师。商红慧副研究员的研究方向是高性能并行算法设计与优化、科学计算程序开发与应用。

### 内构安全研究组

武成岗是中国科学院计算技术研究所研究员级高级工程师、博士生导师，长期致力于基于编译技术的软件安全研究，专注于程序缺陷定位、二进制代码分析优化、运行时行为监测及安全防御等领域。他在国际顶级会议和期刊（如 USENIX Security、TSE、ICSE 等）发表论文30余篇，获授权专利16项，并于2012年获北京市科学技术二等奖。他是首位担任编译顶级国际会议 CGO 大会主席的国内学者，并在 PLDI、CGO 等会议中担任程序委员会委员，具有广泛的学术影响力。

主喆是计算所副研究员，研究方向包括动态二进制翻译、并行程序错误分析、系统虚拟化及系统安全，近年聚焦于基于编译技术、二进制变换和虚拟化的系统安全防御。他的研究成果发表在USENIXSecurity、TSE等顶级会议和期刊上，并承担国家青年自然科学基金项目。

内构安全体系结构实验室的研究方向主要包括：

- 系统安全：利用虚拟化、二进制代码变换和程序分析技术，研究漏洞挖掘、高强度防御机制设计及代码混淆等关键技术。

- 虚拟化：研究全系统虚拟化、进程级虚拟化、虚拟化硬件支持及虚拟机性能优化，提升系统性能和安全性。

- 程序分析：研究并行程序缺陷表征、错误定位、确定性重放及语义提升等技术。实验室的研究成果不仅发表于国际顶级会议和期刊，还应用于国防领域，获得高度评价。研究方向紧密结合编译技术、虚拟化和系统安全，致力于解决软件安全性、可靠性和高效性问题，推动系统安全技术的创新与应用。

### 数据管理研究组

由陈世敏研究员领导，主要研究数据管理系统、大数据处理、并行分布式计算。他于2013年加入计算所，清华本硕、CMU 博士，毕业后先后在美国英特尔研究院匹兹堡研究所、卡内基梅隆大学和惠普研究院工作过。手册评价其学术和个人编程能力很强，从 Vim 配置、编码风格、Code Review 到课题方向和技术细节讨论都会悉心指导，科研和工程能力都能得到很大提升。由于研究方向前沿，硕士研究生或者低年级博士就有可能发表 SIGMOD 和 ICDE 级别顶会论文。主要招直博生，对学生的时间观念要求严格。在招生方面，手册提醒学生与老师确认好是否确定被录；另外手册称毕业时间可能达到8年，并称不保证取得学位。这是手册中的个人经验描述，务必向导师和在读学生核实。

### 操作系统研究组

由孙毓忠研究员负责，研究方向是虚拟机、分布式操作系统。孙老师批评学生的语气和内容异常激烈。
