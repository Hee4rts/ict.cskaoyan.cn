# 处理器芯片重点实验室

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册将其作为计算机体系结构方向的核心科研平台介绍，强调从芯片体系结构到大型计算机系统结构的完整研究链条。

## 主要研究方向

- 高端计算体系结构与微体系结构
- 编译、编程与软硬件协同
- VLSI、容错计算与非传统体系结构
- 高性能计算、智能计算与高通量计算

## 内部实验室与研究组

### 集成电路实验室

聚焦 EDA、芯片测试验证、机器学习硬件加速、专用处理器、硬件安全和低功耗设计。手册提及的细分方向包括区块链加速芯片、硬件木马检测、嵌入式人工智能和测试验证。

### 编译与编程实验室

研究并行编程、多核编程、云计算编程、编译优化、系统资源优化和软件分析。手册还提及面向国产计算平台的高性能编译与二进制翻译工作。

### 并行算法研究组

研究并行算法与并行软件、并行计算模型、性能优化与评测，以及科学计算程序开发。

### 内构安全研究组

把编译技术、二进制变换、虚拟化和程序分析用于系统安全，覆盖漏洞挖掘、安全防御、动态二进制翻译和并行程序错误分析。

### 数据管理研究组

面向数据管理系统、大数据处理、数据库和并行分布式计算开展研究，强调科研与工程能力的结合。

### 操作系统研究组

手册记载该组主要研究虚拟机、分布式操作系统和相关系统软件。
