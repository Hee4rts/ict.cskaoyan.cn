# 分布式系统研究中心

分布式系统研究中心由原计算机应用中心、泛在计算中心和无线中心的部分研究力量重组形成，中心瞄准T3.0万物互联时代分布式计算发展的大趋势，研究和建设下一代智能信息基础设施。以推进信息高铁试验场建设为核心任务，研究分布式计算系统架构原理与方法、分布式系统软件、协议和编程范式等，中心分为5个小组：

- 控域系统组：主要研究云边端协同的分布式智能计算架构、分布式隔离机制、分布式编程方法和边缘计算系统。手册列出的招生导师包括徐志伟研究员、彭晓晖副研究员和张星洲副研究员，并评价该组偏学术研究和新技术系统原型，学生完成任务后老师干预较少。

- 联邦云系统组：主要是云计算、可信计算、unikernel、虚拟化和MLSys相关的工作，该组由唐宏伟老师负责，组内方向选择比较自由，老师很尊重学生自己的想法，组内压力小。

- 无服务计算与分布式可信数据系统组：手册列出的导师为赵晓芳正高级工程师、张程副研究员，方向包括云计算、AI Infra、AI Agent、可信计算和少量 HPC。手册称组内氛围较好、学生较自由，会不定期团建，通常不占用周末。

- 通信与边缘计算融合组：研究边缘网络中计算与通信融合技术和系统，手册列出的招生导师包括田霖研究员、王妮娜副研究员、王园园副研究员，方向偏无线通信。手册评价张宗帅老师团队压力较小、选课自由，学生一定程度上可以选择感兴趣的方向；袁春经老师团队主要研究服务化 RAN。

- 大数据监督系统组：主要研究基于大数据的纪检监督方法和系统，该组由方金云正高级工程师负责。

- 软件系统实验室（http://prof.ict.ac.cn）：主任为詹剑锋研究员，副主任为王磊高级工程师，主要负责制定产业标准，从事数据中心的Benchmarks与操作系统、数据库、搜索引擎等研究，首席科学家是施巍松研究员，组长包括罗纯杰、高婉玲、张帆。

- 原织女星网格团队：组内老师包括李伟副研究员、刘淘英副研究员。组里偏向于工程，主要在公司里做区块链、GPU数据库、教育信息化软件。
