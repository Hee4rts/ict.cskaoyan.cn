# 装备智能系统研究中心

装备智能系统研究中心是为配合国防科工局重大专项工程中心而于2014年组建的部门。手册列出的老师包括毕经平、徐勇军、姚萍、郑天、安竹林、黄建辉、王琪、李超、赵二虎、王飞等。博士生的研究方向一般是未来互联网，硕士生的研究方向根据项目确定；实验室主要研究异构数据融合、网络监控与安全、数字信号处理。

手册记载：毕经平研究员是中心主任，主要做网络测量等；徐勇军正高级工程师研究传感网感知信息融合等，并与网络数据实验室合作；姚萍老师研究数字信号处理与嵌入式系统；郑天老师主要从事空天信息处理方面的工程；安竹林老师研究深度神经网络自动生成与优化；黄建辉老师研究移动机会网络；王琪老师研究强实时无线网络、网络性能分析和优化、无人系统智能组网；李超老师研究边缘智能和网络接入；赵二虎老师主要从事网络通信工程；王飞老师研究可追溯数据融合、序列数据挖掘与分析。

手册认为该中心的研究内容与自动化所综合信息系统研究中心、软件所天基综合信息系统重点实验室有相似之处；整体比较忙，研一时需要经常回所。实验室以工程工作为主，因此手册对就业情况评价较好。
