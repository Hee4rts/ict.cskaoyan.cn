# 智能信息处理重点实验室

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册介绍该实验室覆盖理论型与应用型人工智能研究，对数学基础要求普遍较高，内部包含视觉、自然语言处理、多媒体和智能科学等多类团队。

## 主要研究方向

- 自然语言处理、文本挖掘和智能金融
- 计算机视觉、人脸与生物特征识别
- 多媒体分析、检索和多模态智能
- 图形学、医疗影像、机器人和形式化方法

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
