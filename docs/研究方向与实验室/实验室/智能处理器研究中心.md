# 智能处理器研究中心

智能处理器研究中心（原计算机体系结构国家重点实验室未来计算实验室）由陈云霁研究员和陈天石研究员领衔，手册称其已成为国际学术圈较受关注的学术团队之一，在计算所内部也被认为是有前景的实验室之一，领导和职工学生对中心抱有较高期望。

陈云霁和陈天石兄弟二人都毕业于中科大少年班。手册称二人持续在计算机系统结构领域顶会上发表论文，曾于2014年获得 MICRO 和 ASPLOS 最佳论文，研制了深度学习专用处理器芯片寒武纪。手册认为实验室待遇优厚，参照人工智能和集成电路领域企业的待遇标准，竞争也比较激烈、压力较大。

实验室创立了北京中科寒武纪科技有限公司，以支持研究成果的产业化落地，主要由陈天石老师负责。手册记载，公司天使轮和 A 轮在业内曾创纪录，B 轮达到25亿美元估值；寒武纪产品曾应用于华为手机，并与阿里云合作扩展云端 AI 芯片业务，后来在科创板上市。

手册列出的团队成员包括陈云霁研究员、陈天石研究员（寒武纪）、郭崎研究员、刘少礼副研究员、刘道福（寒武纪）、李威副研究员、喻歆（寒武纪）、杜子东副研究员、罗韬（寒武纪）、张曦珊副研究员、胡杏副研究员、支天高级工程师，并提到徐志伟老师的多名博士生在此团队中。

手册称寒武纪采用联合培养模式，不区分导师；组内方向较自由，带学生的老师较年轻，组内氛围融洽。实验室研究方向包括计算机体系结构和人工智能。
