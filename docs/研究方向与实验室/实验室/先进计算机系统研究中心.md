# 先进计算机系统研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册记载该中心由高性能计算机研究中心独立发展而来，目标是研发先进的数据中心计算机系统。

## 主要研究方向

- 数据中心系统架构
- 存储与数据系统
- 操作系统、协议栈和数据中心网络
- 硬件加速、系统性能建模与开源芯片验证

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
