# 先进计算机系统研究中心

先进计算机系统研究中心是从高性能计算机研究中心独立出来，2011年起挂靠计算机体系结构国家重点实验室，2014年成为正式独立部门，实验室主任是包云岗研究员。中心目标是研发先进的数据中心计算机系统，承担了来自华为公司的一系列合作项目，不过云计算、操作系统和体系结构的方向研究难度不小，对论文发表要求也较高，中心的学生也都很忙，很大程度上需要依靠自己的努力。另外，博士生整体的在学时间也偏长，毕业难度较大。

中心下设：

- 系统结构实验室：主任为陈明宇研究员。陈明宇老师负责内存组，研究主存储器的系统结构，包括内存访问、组织、管理以及访存密集应用优化，成员还有刘宇航副研究员。张文力高级工程师负责网络系统组/数据中心网络组，主要负责工程；刘珂副研究员负责组内科研，方向包括操作系统、协议栈、虚拟交换机（如 Open vSwitch）。张科高级工程师负责硬件组，主要从事硬件加速并承担教学和工程工作；另外还有安全组。手册称整个实验室比较偏工程。

- 数据系统实验室（存储系统组）：主任为熊劲研究员，副主任为蒋德钧副研究员。手册称实验室职工老师较少，学生需要更多依靠自身能力；研一时每周也需要用较多时间回所参与项目任务。

- 前沿系统实验室：主任为包云岗研究员，组内导师还包括石侃副研究员，主要研究数据中心系统架构、软件栈设计与优化、系统性能建模与评价。团队常年承接华为各大部门和阿里的合作研究项目，工程压力较大、标准较高，未来几年将专注 RISC-V，招生比较看重 FPGA 与 Verilog 能力。手册称组内老师在中心学生群体中评价较高；包云岗研究员学术活动较多，仍保持每周组会并尽可能帮助学生争取利益。王升老师较尊重学生想法，组内方向选择较自由，当时包括 MLSys、开源芯片验证、操作系统等方向；组内成员还包括赵地副研究员、解壁伟等。
