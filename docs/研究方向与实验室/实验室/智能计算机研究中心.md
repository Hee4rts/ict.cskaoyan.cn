# 智能计算机研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册将其前身描述为计算机体系结构重点实验室的控制计算实验室，研究覆盖智能芯片、自动导航和集成电路设计工具。

## 主要研究方向

- VLSI 与容错设计
- 智能芯片与机器人操作系统
- 自动导航、无人驾驶和算法硬件加速
- EDA、硬件安全和低功耗设计

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
