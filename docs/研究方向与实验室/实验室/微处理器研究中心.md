# 微处理器研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册将该中心与龙芯团队联系起来，研究覆盖通用处理器及其基础软件，培养地点和项目安排可能与产业团队协同。

## 主要研究方向

- 高性能通用 CPU 设计
- 操作系统与软硬件协同优化
- 专用处理器及 IP 设计
- AI 加速、芯粒互联与互联协议

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
