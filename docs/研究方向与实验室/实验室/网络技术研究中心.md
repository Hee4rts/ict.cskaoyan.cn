# 网络技术研究中心

!!! warning "手册原文整理"
    以下内容根据《2025版计算所信息手册 2.0》扫描页整理，保留了手册中的实验室背景、团队、导师、培养、项目、待遇与就业等描述。手册并非官方材料，其中的个人评价和时效性信息未经本站核验，不代表本站事实判断；报考前请向实验室和导师本人确认。

网络技术研究中心是历史比较悠久的部门，科研和工程实力都不错。手册认为其研究方向不算工业界主流，因此不是热门实验室，保研和考研难度都不算大。实际项目工作可能比较杂，只要与方向有一些关联就可能参与；学生在怀柔集中上课期间大概一两个月回一趟所里开组会，平时通常不会布置具体工作。包括以下课题组：

- 网络体系结构与系统课题组：李振宇老师组的研究方向是互联网体系结构、内容分发网络，成员包括武庆华老师、王阳老师。姜海洋老师组对操作系统和算法基础要求较高，科研强度和工程任务量都较大。关洪涛老师组主要搞偏向路由器的方向。张广兴老师组主要在南京做工程项目。武老师对学生很负责

- 智能网络与系统课题组：张玉军老师组主要研究下一代互联网，偏向网络安全，成员包括王淼老师；朱树永老师主要研究网络体系结构，涉及确定性网络、在网计算和算力网络；孟绪颖老师方向偏向网络大模型。手册称张老师是实验室主任，教学能力强、性格温和，其学生一般会跟随朱老师或孟老师，组内老师对学生较负责。

- 移动互联课题组：刘敏老师组研究移动计算、无线网络、移动互联网。

- 互联网基础技术实验室：李晓东研究员是主任，与 CNNIC 共建。

- 区块链技术实验室（创新工场-计算所区块链与分布式应用联合实验室）：孙毅老师是实验室主任，研究区块链、互联网视频分发、网络测量和数据中心网络，成员包括张瀚文、于雷老师；李忠诚老师是实验室首席科学家。

- 金融大数据分析课题组：宋新波副研究员负责，研究方向是金融科技领域大数据分析、信息内容安全，主要使用Python，对数学要求较高。
