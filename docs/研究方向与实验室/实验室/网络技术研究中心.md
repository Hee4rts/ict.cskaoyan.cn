# 网络技术研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册将其描述为历史较久、科研和工程并重的网络技术部门，下设多个网络体系结构、移动互联和应用方向团队。

## 主要研究方向

- 互联网体系结构、内容分发与路由
- 确定性网络、在网计算和算力网络
- 移动计算、无线网络与移动互联网
- 区块链、网络测量和金融科技数据分析

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
