# 泛在计算系统研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册记载该中心由普适计算、传感器网络和物端系统等研究力量合并成立，研究贯穿感知、人机交互、移动智能和物端计算。

## 主要研究方向

- 感知计算与多媒体通信
- 人机交互、声音事件识别与深度学习
- 移动智能、嵌入式系统和空间定位
- 物端协同、智能图形、生物医学信息与低功耗芯片

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
