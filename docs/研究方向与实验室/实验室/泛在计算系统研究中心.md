# 泛在计算系统研究中心

!!! warning "手册原文整理"
    以下内容根据《2025版计算所信息手册 2.0》扫描页整理，保留了手册中的实验室背景、团队、导师、培养、项目、待遇与就业等描述。手册并非官方材料，其中的个人评价和时效性信息未经本站核验，不代表本站事实判断；报考前请向实验室和导师本人确认。

泛在计算系统研究中心成立于2017年1月，由原普适计算研究中心、网络技术研究中心传感器网络实验室、体系结构重点实验室物端系统研究组合并成立。手册称中心会从芯片、系统、网络、应用等不同层面实现物端生态系统；中心主任是陈益强研究员，副主任是崔莉研究员，徐志伟研究员负责中心整体方向规划。包括：

- 感知计算课题组：中心主任是陈益强研究员。纪雯老师研究信息编码与多媒体通信网络，涉及视频编码、视频传输、无线视频通信、信道编码、联合信源信道编码、网络经济、信息论和优化方法、社交媒体、泛在计算等理论方向；谷洋老师研究无线定位。二部/中科辅龙公司的唐卫清研究员、何涛副研究员的招生名额挂靠中心。手册称陈老师下属几个组的学生自由度相对较高，导师普遍尊重学生想法，压力相对较小。

- 人机交互课题组：王向东老师为组长，以前做过手语翻译、爱心小屋、情境感知、科技助残，现在主要做声音事件识别、深度学习工程、弱监督和无监督学习，同时指导钱跃良老师的学生。团队还包括刘宏老师。

- 移动智能（嵌入式系统）课题组：每个老师都是独立团队，以工程为主。朱珍民老师做生命体征与环境情境感知计算、健康移动和穿戴式计算技术；叶剑老师做面向大数据交易的数据挖掘、情境感知、智能终端应用研发；罗海勇老师做全空间定位、基于众包室内地图构建、传感器网络。

- 物端协同计算课题组：梁英老师主要从事大规模数据分析挖掘工程；史红周老师从事嵌入式系统、Web 工程和区块链，并参与公司项目。

- 传感器网络课题组：手册将其与北京中科天合科技有限公司联系起来，主要研究传感器网络和物联网，负责人是崔莉研究员。方向包括传感器器件研制、组网协议、系统软件设计、信息处理与应用系统，成果偏重系统，也有论文输出。团队还包括赵泽、黄希等老师；赵泽老师主要负责公司运营。手册称往届学生主要进入电子类国企、网络类外企，也有人进入互联网公司和银行。

- 智能图形处理：高林副研究员在智能计算机图形学和三维计算机视觉领域开展研究。手册提到其学生发表过 SIGGRAPH 论文，也有人在相关团队实习并发表 ACM SIGGRAPH/TOG、CVPR、AAAI 等论文，部分学生获得国外高校 offer。

- 生物/医学信息学课题组：赵屹研究员很支持学生的个人想法和理想，主要做公司，学生在团队开办的精准医疗领域公司（北京中科晶云科技有限公司）里学习，方向是医学组学数据挖掘分析、生物复杂网络、非编码基因预测功能注释、遗传病及肿瘤组学等。赵屹老师研究组偏向于基因芯片、微电子。

- 物端计算系统实验室（中科物栖（北京）科技有限责任公司（Jeejio)）：成立于2015年，主要涉及物联网、智能硬件、可穿戴设备等领域，实验室主要工作偏重工程研发。实验室主任是徐志伟研究员，负责人是张磊研究员，张磊老师都会参与实际的编程开发工作，现在工作重心主要集中在可重构计算、定制计算在物端和边缘计算系统中的应用，是中科院海外引进人才。首席科学家是intel中国研究院前首席科学家王元陶，研究移动微型低功耗芯片集成，例如将芯片集成在小蜜蜂这样的昆虫上。这个实验室的保研难度不高，考研难度不小，大部分组的学生读研时的待遇也非常不错。因为这个实验室主要做工程，而且实际上与网络数据实验室做的东西有很多相似之处，所以就业不错。
