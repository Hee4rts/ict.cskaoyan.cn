# 网络数据科学与技术重点实验室

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册介绍该实验室兼具网络数据研究与工程系统建设，方向随网络空间治理、信息检索和数据挖掘等任务展开。

## 主要研究方向

- 信息检索与数据挖掘
- 网络舆情和社会计算
- 网络空间数据分析
- 应用系统研发

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
