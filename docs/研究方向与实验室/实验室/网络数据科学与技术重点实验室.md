# 网络数据科学与技术重点实验室

!!! warning "手册原文整理"

网络数据科学与技术重点实验室是2013年筹建的院级重点实验室，之前称为网络数据科学与工程研究中心，手册提到中科天玑公司与实验室有关。手册认为实验室在学术和工程项目方面都很活跃，工程项目较多，因此保研生源较热门、就业前景较好；研究内容比较杂，常跟随项目调整，除了信息检索、数据挖掘、网络舆情分析外，还会开展各种应用开发项目。

手册的主观评价认为，部分项目“听起来高大上”但实际价值和最终效果不一，也把实验室的发展放在当时大数据热潮的背景下理解。与此同时，项目较多使学生成果和简历内容比较丰富。手册称实验室管理较严，基本不能外出实习；待遇不错，过去不少成员以工程为主，工程压力较大，研究方向随热点变化，较适合硕士毕业后就业，并提到实验室等级观念较强。

手册称实验室学生不按导师固定分组，而是由实验室主任指定老师统一分配到各组，因此学生可能在名义导师组内，也可能被安排到其他组。博士培养通常是硕博连读或直博：第一年与其他学生在雁栖湖校区集中上课，第二年进入项目组全力做工程，完成三至四年工程工作后进入基础研究组开展科研，发表论文并达到毕业要求后毕业。

博士生在工程阶段通常根据项目组工作内容确定未来研究方向。手册提醒，如果中途项目组负责人离开计算所，培养安排可能受到影响，不过也称这种情况一般不会出现。基础研究组发表过不少顶会论文，兼具科研和工程实力，并为申报重点实验室组建过论文写作团队。手册记载实验室具体工作由郭嘉丰研究员领衔，靳小龙研究员共同负责学术工作；其观点是该实验室可以读博，虽然毕业不如体系结构重点实验室容易，但研究方向的就业面仍然较宽。
