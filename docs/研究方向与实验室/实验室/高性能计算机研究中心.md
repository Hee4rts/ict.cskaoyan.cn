# 高性能计算机研究中心

!!! warning "手册原文整理"
    以下内容根据《2025版计算所信息手册 2.0》扫描页整理，保留了手册中的实验室背景、团队、导师、培养、项目、待遇与就业等描述。手册并非官方材料，其中的个人评价和时效性信息未经本站核验，不代表本站事实判断；报考前请向实验室和导师本人确认。

高性能计算机研究中心（国家智能计算机研究开发中心、国家高性能计算机工程技术研究中心、国家并行计算机工程技术研究中心计算所分部）曾经实力很强，曙光即源自于此。手册称其近年经历过多次剥离（先进计算机系统实验室独立、信工所组建等），规模缩小，并搬到计算所新园区。学生住宿在青年公寓，中心办公区配有冰箱和洗澡间等便利设施，楼下有免费的篮球场和羽毛球场；早晚有班车，单程约40分钟，后来开通地铁后更方便，但相较计算所本部仍然较远。手册还记录了新园区食堂及到对面华为公司食堂就餐等生活体验。

中心管理比较宽松，手册评价秘书做事认真负责、工资发放及时，但某些组待遇相对其他实验室较低。手册记录，当时实验室考勤与每月 RA 挂钩，采用灵活考勤制度：每天工作满8小时得30元，6-8小时得15元，低于6小时当天没有补助；该规则明显具有时效性。

手册认为，由于国家对高性能计算研究支持力度变化、曙光公司更重视衍生行业商业拓展等原因，大机器研制项目已很难再有。中心当时主要承担科技部重点研发任务、院先导专项和重大仪器专项等，并与曙光公司、中科院大气所等联合研制地球模拟器大科学装置。中心使命由大机器研制转向面向国家战略应用和产业发展需求的高性能计算关键技术；手册同时给出了“缺乏实质性重大成果”的主观评价。

2016年底，中心进行了调整，中心分为并行算法、系统软件和体系结构三个方向，由6个课题组构成，课题组长和骨干几乎都是孙院士的毕业留所的学生。谭光明研究员担任中心常务副主任。原算法与体系结构组在实验室调整后发展成三个组（计算科学组、数据科学组和新型结构组）。

- 计算科学组：手册列出何鑫、肖俊敏、王银山等老师，主要研究传统科学计算应用的并行和优化，如激光聚变、全球气候模拟、大规模图计算等。手册评价肖俊敏老师投入度很高，同时对学生要求可能较严格。

- 数据科学组：手册列出姚二林副研究员、张春明高级工程师，主要研究生物医学图像处理和基因数据分析。该组与计算所其他生物信息团队不同，不以算法研究为主，而是把生物信息和机器学习作为高性能计算的一类应用。

- 高性能数据处理系统组：组内有陶鼎文老师和刑晶老师，该组主要研究数据压缩，陶老师对打卡没要求，对学习和科研地点没有特点要求。组内薪资不错。

- 系统互联组：组内有王展老师和邵恩老师，该组主要研究高性能计算机系统中的部件互连网络。王展老师组横向比较多，工资会比其他组高，但论文产出会相对少一点.

- 新型结构组：臧大伟老师，该组主要研究In-memoryprocessing、RISC-V、光计算等新结构。

- 技术平台组：主要从事产业化工作，以各种项目的工程开发为主。

- 算法应用课题组（BioinformaticsandGreenNetworkLaboratory）：http://ear.ict.ac.cn，张法研究员团队成果很多，另外张法老师非常和蔼。团队从事生物医学显微图像处理和高效能数据中心方面的优化和算法研究。导师有刘志勇研究员、张法研究员、万晓华副研究员。

- 贾伟乐老师组很强，组内氛围也不错。实验室中的很多博士都挂在孙院士名下，孙院士每周都开论文讨论班，他的所有学生都需要参加并汇报情况。另外有些学生会被安排到曙光公司实习，在曙光公司做的事情对自己的技术水平提高帮助很小，不是很有意义，不过待遇会更高。计算所部分分所的学生也挂在中心，但与中心完全无关，包括顺德分所负责人陈冰冰老师（PLC）的名额。高性能实验室新加入陶鼎文老师水平也是非常厉害，欢迎大家报考。
