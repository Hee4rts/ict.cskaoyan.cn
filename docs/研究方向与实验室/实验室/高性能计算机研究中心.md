# 高性能计算机研究中心

!!! warning "信息时效与来源"
    本页根据《2025版计算所信息手册 2.0》整理。手册包含非官方经验信息，实验室名称、负责人、研究方向、培养方式和招生情况均可能变化；报考前请以计算所官网、实验室主页和导师当年回复为准。

## 手册概述

手册回顾了该中心与曙光、高性能计算平台的历史联系，并介绍其当前面向国家战略应用和产业需求开展关键技术研究。

## 主要研究方向

- 高性能计算系统与系统软件
- 并行算法和科学计算
- 高性能数据处理与压缩
- 系统互联、新型体系结构和行业应用

## 报考时建议确认

- 当年是否招生、招生专业及名额归属
- 实际指导老师、培养地点与联合培养安排
- 科研与工程项目的时间占比、实习政策和毕业要求
- 与自己背景相匹配的基础课程、编程或硬件能力要求
