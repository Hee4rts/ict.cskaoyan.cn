# 复试规则

> 官方来源：[计算所硕士招生](https://www.ict.ac.cn/yjsjy/zsxx/)


26年复试详情

英语能力测试、计算机专业能力考查和综合素质考察等。

1.英语能力测试

英文自我介绍（2分钟）。注：不同年份可能不一。如25年是中文自我介绍

2.面试抽题

从三个题库分别中抽取三道题。覆盖范围有组成原理、编译原理、机器学习等。较难准备，答不出来也没关系。

3.简历问答（重重之中）

考官会根据你的简历和你的成绩单对你进行提问，此为面试的核心过程，建议好好准备自己的简历。


每位考生的复试面试总时长一般不少于20分钟。

注：不同年份的复试形式可能不同，不应直接套用往年流程。
